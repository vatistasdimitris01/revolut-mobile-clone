# Revolut Mobile Clone

Exact mobile-only UI clone of the Revolut home screen (based on the provided screenshot).

## Features
- Pixel-close recreation of the Revolut mobile home screen (dark theme + aurora gradient)
- **Custom balance** – tap the ✎ button or use Customise → Edit balance
- **Add custom expenses** – Customise → Add custom expense (e.g. Food, OpenAI membership)
- Loading screen with animated logo
- PWA ready (installable on home screen)
- Fully mobile-first (shows a message on desktop intentionally)
- Data saved in localStorage

## Deploy to Vercel (fully working)

1. Go to [vercel.com](https://vercel.com) → **New Project**
2. Import the repository: `vatistasdimitris01/revolut-mobile-clone`
3. Click **Deploy** (zero configuration needed)

Or with CLI:
```bash
npx vercel
```

After deploy you can open the URL on your phone and **Add to Home Screen** for the full PWA experience.

## Local preview
Open `index.html` on a real phone or in Chrome DevTools device mode (iPhone / Pixel).

Made exclusively for mobile.
